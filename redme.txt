# 🦐 小虾米 · 环境自适应智能体（最简状态）

> 部署到任何环境：先探测环境条件 → 需要什么技能时按条件生成 → 越用越聪明（自优化 + 记忆）。
> **当前为最简状态**：不预置任何技能模板，Windows 上启动即为"纯聊天 + 记忆"，
> 技能全部由 LLM 按需生成（说"新增技能：XXX"）。

## 一、核心概念

**"条件即技能"**：小虾米启动时探测环境（能力清单 `data/capabilities.json`），
聊天中你需要它做什么，它就按能力清单让 LLM 生成对应技能；技能用不好就自己修（自优化闭环）；
经历全部记下来（永久记忆）。换一个环境，重新探测、重新学习。

## 二、快速开始（Windows 开发环境）

```bash
cd shrimp_agent
pip install -r requirements.txt        # 轻量：只需 Web + 请求库
copy .env.example .env                 # 填入 API_KEY
python -m uvicorn main:app --host 0.0.0.0 --port 8000
# 浏览器打开 http://localhost:8000
```

## 三、环境能力三通道

| 通道 | 方式 | 说明 |
|---|---|---|
| ① 主动提供 | 项目根放 `environment.json` | 部署者直接声明硬件（如舵机/屏幕/麦克风） |
| ② 自动探测 | 启动自动探测，**平台驱动** | 先探测平台，再按平台查必要能力：Linux 查 I2C/GPIO/舵机板/OLED，Windows/macOS 只查网络/音频/摄像头/可用库 |
| ③ 界面修正 | `POST /environment` | 查看/修改能力清单，改完自动生效 |

最简状态不假设任何硬件：Windows 上探测结果只有 `platform/python/network/libs`，
不会凭空生成技能。声明了能力才可能生成对应技能，例如：

```json
{ "display": {"type": "display"}, "network": true }
```

## 四、说话方式

| 你说 | 小虾米做 |
|---|---|
| 我叫小明 / 我喜欢蓝色 / 记住我每天7点起床 | 记入永久记忆 |
| 查看记忆 / 我是谁 / 忘记名字 | 读/删记忆 |
| 新增技能：XXX | LLM 按能力清单生成技能（迭代校验，最多3轮） |
| 执行 / 打开 / 运行 XXX | 执行技能（失败自动进入自优化） |
| 修复技能 XXX | 手动触发自优化（五步验证链+备份回滚） |
| 列出技能 / 删除技能 XXX | 技能管理 |

## 五、自优化安全边界

- **T0 系统核心**：禁止自动修改
- **T1 环境基础技能**：失败自动修复
- **T2 学习生成技能**：自动修复；连续失败≥2次自动停用，等主人确认
- 每次修改前：语法编译 → 能力约束校验(AST) → 模拟执行(dry-run) → 备份 → 热重载 → 失败回滚
- 每日自动修改上限（默认10次），全部修改写入 `data/optimize_audit.json` 审计日志

## 六、硬件抽象层（可选扩展）

技能代码只依赖 `hardware` 抽象层（默认 PC 模拟器，装上驱动库自动切真实后端）：

```python
from hardware import hw
hw.servo("leg_1").set_angle(90)          # 舵机（需在能力清单声明 actuators）
hw.display().show_emoji("😊")            # 屏幕
hw.mic().listen(3)                       # 麦克风
hw.speaker().say("你好")                 # 说话（TTS 预留）
```

- PC 上默认**模拟器**：状态可查 `GET /hardware/state`
- 树莓派装好 `smbus2`/`luma.oled`/`pyaudio` 后自动切真实驱动（`hardware/real.py`）
- **最简状态不生成任何硬件技能**；需要时通过 `environment.json` 声明能力后，
  聊天中让 LLM 按清单生成对应技能

## 七、接口速览

```
GET  /environment        查看能力清单与探测结果
POST /environment        手动修正环境能力
GET  /skills             技能列表
POST /skills/create      按描述生成技能
POST /skills/fix         修复技能
GET  /skills/stats       技能档案（成功率/连续失败）+ 优化审计
POST /skills/suggest     学习器建议新技能
GET  /hardware/state     模拟硬件状态
POST /chat               聊天（自动分发：记忆/技能/云端）
... 记忆接口同旧版：/memory/*, /history/*
```

## 十、部署到手机（Termux · 安卓）

小虾米可以在**安卓手机本地直接运行**（Termux 终端），不依赖电脑。

### 步骤

```bash
# 1. 安装 Termux（建议从 F-Droid 安装，Play 版已停更）
#    下载地址: https://f-droid.org/packages/com.termux/

# 2. 把整个 shrimp_agent 文件夹放到手机里
#    - 方法A：USB 连接电脑复制，或文件管理器传到 Download 目录
#    - 方法B：先推到 Git 远程仓库，再在 Termux 里 git clone

# 3. 在 Termux 里执行（先授权存储再进入目录）
termux-setup-storage
cd /sdcard/Download/shrimp_agent   # 换成你放文件的路径
bash setup_termux.sh               # 一键安装：Python + 依赖 + .env

# 4. 配置 API Key
nano .env                           # 填入 API_KEY，Ctrl+O 保存，Ctrl+X 退出

# 5. 启动
python main.py

# 6. 手机浏览器打开
#    http://localhost:8000
```

### 提示

- **局域网访问**：手机和电脑同一 WiFi 时，电脑浏览器访问 `http://手机IP:8000`
- **后台运行**：`python main.py &` 或安装 Termux:Boot 实现开机自启
- **依赖全纯 Python**：无编译（已去掉 pydantic 重依赖），安装快、兼容 arm64
- 手机环境的硬件探测（舵机/屏幕等）会自动失败降级，技能照常工作；
  桌面类技能（记事本/计算器）在手机上可能不可用，可用「删除技能」清理
